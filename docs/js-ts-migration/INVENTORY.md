### How to read the tables

- **Order**: suggested conversion order *within the stream* — leaf-first (fewest same-graph importers first). Types propagate to callers, so converting leaves first minimizes churn.
- **JS imp / TS imp**: number of other `app/` files (already-JS / already-TS) that import this file (in-degree).
- **Leaf**: `yes` = imported by no other `app/` file (safe to start anywhere).
- **Cross-stream importers**: which *other* workstreams import this file. Files with cross-stream importers should be converted **first, in their owning stream**, before dependent streams type against them.
